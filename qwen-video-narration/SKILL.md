# Qwen 视频配音

交付可播放的配音视频、代表性试听和同步字幕。保留用户指定的模型、音色、语速和既有授权。可独立处理已有视频；修改 Manim 场景时再使用当前环境中适用的 Manim 技能。

## 准备

随附脚本以本文件所在目录为基准定位。离线检查文稿需要 Python 3.10+，音频处理需要 FFmpeg 和 ffprobe，实际合成语音还需要可访问千问服务并配置密钥。项目文件和交付物以视频项目为基准定位。

- 检查已有视频、文稿、脚本、缓存和密钥配置。中间文件统一放在项目 `tmp/<本次配音任务>/`，最终文件放入交付目录；不要把用户音频、缓存或密钥写进技能目录。
- 明确哪些画面时间点必须保持。固定成片需要语音适应时间窗，可重新渲染的动画可以适应新配音。两者不明且影响结果时先澄清。
- 沿用已授权的服务和声音，不重复索取许可。密钥缺失时请用户在本地安全配置 `DASHSCOPE_API_KEY`，不要要求其粘贴到聊天；检查时只报告是否存在。
- 首次调用某模型或改变能力假设时，核实官方的模型名、音色兼容性、地域、端点和参数。读取 [接口与调音经验](references/qwen-api.md)，不要混用相似模型系列的端点和字段。

## 视听脚本先行

新建或可重新生成动画的配音视频，按“原文 → 完整视听脚本 → 逐句配音 → 实测时间轴与完整音轨 → 动画 → 合成”执行。用户只要求配音或为固定成片换声时，保留对应模式，不擅自扩展为重做全片。

先用 `manim-composer` 或等价方法完成 `scenes.md` 与 `video_script.json`。每句稳定 `id`，分开写准确 `narration`、对应 `subtitle`、画面文字 `screen_text`、静默小字 `screen_notes`、动画内容 `animation` 和必要的 `pause_after`。只把 `narration` 送入 TTS；标题、公式标签、小字和动画说明不能自动并入朗读内容。旧的 `text` 列表输入仍可兼容。

常规“数值为教学示意”“不代表真实模型权重”等说明只在画面小字显示，不在每个例子或主题末尾口述，也不放进逐句旁白字幕。影响推理的关键前提在需要时讲清楚一次，避免把必要条件一起删掉。

每句单独合成；不要将整段合成为一个文件后按字数均分句子时间。先把长句改写成自然短句，避免机械按逗号、分号或小数点切开。默认短句尾停顿为 0.2 秒，可由每句 `pause_after` 或项目配置调整；推导、观察和转场的停顿显式写进脚本。不按未来动画长度给每句统一设置较大的 `min_duration`。

## 文稿与试听

字母、变量名和英文缩写直接保留原字符交给 Qwen，例如 `n`、`d`、`i`、`l`、`x`、`A`、`I`、`LN`、`MLP`；希腊字母也可直接保留 `γ`、`β`、`ε` 等符号。不要预先改成“恩”“迪”“艾勒”“艾克斯”“诶”等中文音译，也不要基于对 TTS 发音能力的猜测加入近似读音。

用自然中文说明下标、转置和运算范围，例如“x 下标 l”“A 的转置”，其中字母仍保留原字符。修订已有音译稿时，根据公式恢复正确的字母、大小写与索引，不做可能误伤“维度”等正常词语的全局替换。

数学文稿先处理分数、负号、偏导、逆矩阵、括号和幂的作用范围。例如 `(y-x)^3` 读成“把 y 减 x 这个差取三次方”；显示字幕可保留数学记号。

1. 音色未定或用户不满意时，先生成开场和含公式的一小段，标注真实模型、声音与设置。
2. 优先用官方支持的生成指令和 API 参数调整声音。用户不喜欢后期变调时，从文稿重新合成，不能用本地降采样或变速冒充 API 调整。
3. **请求成功不代表调音生效。** 对同一文本比较原始音频；完全相同说明本次未产生可观察的变化。文件不同也不能证明更低沉、更自然，仍需试听。基频分析只能辅助判断，不能替代听感。
4. 用户仍反复调整声音时给出短试听，等待偏好反馈，不对每个候选立即生成全片。若用户已经给定设置并授权完成整片，样本检查后可直接继续；试听不是固定的再次审批步骤。
5. 两种有依据的控制方式仍不产生目标效果时，说明实测限制并提出替代音色试听；不得擅自更换用户指定的模型或声音。

## 生成与缓存

使用 [scripts/qwen_tts.py](scripts/qwen_tts.py) 调用 Qwen-Audio-TTS HTTP 接口；输入格式和命令见 [脚本与同步](references/workflow.md)。其他模型系列按对应官方文档实现。

- 先用 `plan` 检查逐句旁白，再用 `synthesize --ids ...` 生成样本；选定后合成全部并复用缓存。完整请求参数不变时，修改小字、标签或动作说明不应重新收费合成旁白。
- 缓存键覆盖端点和全部实际请求参数。保留原始 WAV、无密钥配置、接口字符用量和音频摘要；变化的请求不能误用旧缓存。
- 不记录鉴权头、密钥、完整异常或签名音频 URL。缓存原子落盘；结果不确定时不无限重发。查明失败状态后，在原有授权范围内进行有界重试。
- 费用按接口 `usage.characters` 和当前地域价格折算，区分估算原价、实际扣费、免费额度及额外 ASR 费用。普通字数不等于计费字符；不要在技能中固定单价。
- 本地可统一音量和采样率，不无依据地变调或强行加速、裁切语音来凑时长。

## 以声音时间轴制作动画

读取 [脚本与同步](references/workflow.md)。全部句子配音完成后，先运行 [build_audio_timeline.py](scripts/build_audio_timeline.py)，核对全文 ID 和旁白、探测真实音频，生成完整音轨、逐句 SRT 和固定 `audio_timeline.json`。每句记录 `start`、`end`（语音结束）、`window_end`（含停顿）；未完成整片配音或只有试听子集时不能进入正式动画阶段。

- 动画只读取声音阶段确定的时间轴，字幕也使用同一组 ID 和时间戳。句子时间不等于句内词时间；需要词级同步时须有真实对齐结果。
- 渲染时记录实际开始用于校验，不能用动画时长重新决定后续语音起点。动作超时先简化；确需增加停顿时先修改脚本并重建音轨和时间轴，再更新下游画面。不能裁掉句尾或无依据地强行加速。
- 分章渲染需要按固定全片时间换算本章时间，并检查实际章节时长；不能在每章结尾任意增加等待。
- [assemble_narration.py](scripts/assemble_narration.py) 的新模式复用声音阶段的完整音轨；另保留已有成片的 `actual_start` 列表模式。工具替换原音轨，需保留背景声的混音另行处理。
- 抽听开场、句子衔接与术语。数学内容可使用已授权的 ASR 辅助检查；识别正确不代表音色自然，不声称听过未实际听取的音频。
- 检查语音完整、逐句字幕同步、小字可读且未被朗读、声画意义匹配以及文件可完整解码。交付完整视频和按需提供的音轨、字幕、视听脚本与源码，说明实际声音控制方式。
