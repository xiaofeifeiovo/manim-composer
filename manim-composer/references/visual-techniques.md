# 以观察任务组织可视化

在设计场景和动画动作时阅读。这里描述数学对象如何被展示、操作与比较；具体 API 由所选 ManimCE 或 ManimGL 实现技能处理。

## 先决定希望观众发现什么

为每段写一个观察任务，例如发现两个分量抵消、发现参数位置决定响应行为，或发现同一假设推出两个不兼容的结果。随后确定需要哪些对象、改变什么、保留什么，以及怎样比较。

结束状态应留下支持本段观察的结果或关系。对应的场景字段见 [脚本契约](audio-first-script.md)，可照 [场景模板](../templates/scenes-template.md) 填写。

## 让变化对应运算或推理

| 关系 | 可采用的动作 | 需要维持的数学对应 |
|---|---|---|
| 缩放、反向 | 改变箭头长度或方向 | 比例、符号及原对象身份 |
| 旋转 | 围绕明确中心转动 | 起始位置、角度与方向 |
| 分量相加 | 分量首尾相接，显示合成结果 | 每个分量如何贡献到结果；必要时移动副本以保留原图 |
| 代入或公式变形 | 对应项逐步替换、移动、合并 | 新表达式来自原式哪一项，以及等式成立的条件 |
| 累积或积分 | 局部贡献加入，总量同步更新 | 单步贡献与总量的联系；面积、向量等表征须适合被积对象 |
| 参数影响 | 参数标记移动，响应视图同时变化 | 明确本次改变的量和保持不变的条件 |
| 局部到整体 | 一个对象 → 多个对象 → 全体 | 前面解释的规则怎样应用到每个对象 |
| 逻辑矛盾 | 前提及各自结果并列 | 针对同一假设、同一对象的不兼容结论 |

选择适合对象的表征：向量可用箭头，矩阵可用网格与基向量的映射，导数可用切线斜率或位置与速度，函数可用输入输出关系。不要把每种运算都硬套为箭头或几何变形。

## 逐步建立复杂性并保留身份

先建立一个可理解的关系，再扩展到多个对象、参数或视图。已知完整公式或最终图可以作为开场目标或上下文，随后隔离当前要解释的部分；不要求每个公式都从空白逐字出现。

沿用已建立的对象，或将它缩成有用的参照。变换表征、移动布局时，通过标签、对应颜色、连线或连续运动交接身份。只有在确有对应关系时使用形态变换，避免让视觉平滑暗示未经说明的数学等价。

保留仍用于比较的对象，淡化或移除完成任务的元素。信息量过大时先展示局部，再展开整体；必要时回放并提供新的观察角度。

## 跨场交接真实的计算结果

前场输出被后场使用时，先确定具体是哪一个对象、哪一行/项、数值和形状是什么，再设计转场。沿用对象的标签与索引；移动或复制已有结果到新运算的位置，必要时保留缩略参照。分章独立渲染也要在下一章恢复可识别的结束状态，接着完成交接。不能每章清空重画、换一组数字，只靠“接下来”或相同配色声称连续。

切换示例、抽取局部、重新排序或从数值推广为符号时，在切换处给出映射。该输出怎样成为下一步输入必须在旁白与动作中同时可辨认。单场截图看不出这项质量，应连看交界前后的解释与动作。

### 例：同一行权重如何形成同一个输出

以下是计算连续性的范例，不是所有题材必须采用的公式或布局。先约定接收/查询位置为 i，提供键值的位置为 j，A∈Rᵐˣʳ，V∈Rʳˣᵈᵛ，O∈Rᵐˣᵈᵛ；vⱼ 是 V 的第 j 行，oᵢ 是 O 的第 i 行。

1. 在打分矩阵中固定第 i 行，展示按该行归一化。可用分数 (ln 2, ln 3, ln 5)，逐项指数得到 (2,3,5)，除以总和 10，得到 aᵢ=(0.2,0.3,0.5)。原分数、结果和行索引之间有可见对应。
2. 下一场保留这条 aᵢ 及三个列索引，不换数值。把 aᵢⱼ 分别连到 V 的第 j 行 vⱼ，而不是把整条权重行只配给 V 的第 i 行。
3. 使用 v₁=(1,0)、v₂=(0,2)、v₃=(2,2)，移动权重副本至对应向量旁，展示 0.2v₁=(0.2,0)、0.3v₂=(0,0.6)、0.5v₃=(1,1)。原权重行仍可参照。
4. 把这三个贡献相加得到 oᵢ=(1.2,1.6)，再把结果放回 O 的第 i 行。i 标识哪个接收者得到输出，j 标识遍历了哪些值向量。
5. 退回整体图，用同一批对象连出“匹配打分 → 按行归一化 → 值向量加权汇集”，对应 oᵢ=Σⱼaᵢⱼvⱼ、O=AV，解释这回答了怎样按需汇集信息的问题。

若使用不同数值，应沿链条重新计算；归一化后的权重不能在下一场凭空替换。这种检查也适用于证明的条件传递、物理状态演化和函数复合。

## 按关系选择布局

| 需要同时理解的关系 | 布局选择 |
|---|---|
| 参数与响应 | 参数区与响应区分开，更新对应 |
| 分量与整体 | 分量放在较小区域，合成结果使用主要区域 |
| 条件、方法或前后状态的比较 | 对应位置和可比较的尺度；改变尺度时明确提示 |
| 局部与全局 | 保留整体参照和局部细节，说明对应位置 |
| 已知前提与当前推理 | 小窗或简短条件作为持续参照 |

左右与上下顺序按内容调整。主图、公式和文字靠近其对应对象，避免机械使用固定的标题—主图—公式版式。多个面板应承担明确的比较任务。

## 颜色、注意力与镜头

同一推理范围内，颜色、标签与位置帮助追踪对象。高亮讨论中的部分，淡化暂时无关的内容；若颜色含义变化，清楚交接。文字和必要标记使含义不只依赖颜色。

镜头移动应解决具体观察问题：看清方向、消除遮挡、放大细节、建立局部与整体的联系。比较前后状态时保留稳定坐标或参照。坐标名称、单位和尺度按理解需求标明。

主画面文字保留需要参照的标签、条件、公式和短结论，给图形足够空间；完整字幕可另设一层。黑底、配色、角色、三维和幽默属于可选表现手段。

## 声画配合与时间

常用顺序是建立对象、引导观察、实施变化、解释结果、保留结论或引出问题。按内容调整，不要求每句旁白触发新对象或切镜头。

检查对象何时被解释、何时需要观察变化、何时需要理解结果。谈到某个对象时应清楚可见，解释结果时应保留相关证据。复杂处可以简化、减慢、保留对照或回放。

正式动画服从实测旁白与明确停顿；不把固定动作秒数、快慢节奏表或字数估计当成生产时间轴。需要增加观察时间时回到脚本与音轨安排，不擅自在章节末补长等待。

## 示意与论证边界

区分数值例子、局部示意和一般论证。说明会改变结论的假设及不变量；不要让一个漂亮的局部动画看起来已经证明了全局结论。反证法中的假设对象无法真实构造时，明确替代示意展示的范围。

审查每段：观众能否辨认对象、追踪结果来源、看见所需比较，并说出观察支持的结论？删减没有承担这些任务的元素或动作。
