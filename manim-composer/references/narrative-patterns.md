# 叙事路线与旁白组织

在建立或修改数学、物理及技术解释视频的讲述路线时阅读。以下方法从欧拉公式、拉普拉斯变换和毛球定理视频的分析中提炼；它们帮助作出创作选择，不规定统一开场、情绪曲线、镜头数量或时长。

## 先确定理解目标

明确观众已经知道什么、卡在哪里，以及看完应能解释、预测或判断什么。例如“能从参数位置判断运动是衰减还是增长”比“理解复指数”更能指导内容取舍。让每个场景的问题推进这个目标。

需要补充前置知识时，说明它解决哪个理解困难；观众已经掌握的部分可以直接作为参照。沿用用户确定的观众、深度与时长约束。清楚解释优先于预估片长：必要时增加前置知识、定义、推导和总结，可以让视频更长、内容更深入。不要靠加速旁白、删掉中间步骤或把关键定义移到难读的小字来维持时长；用户明确的硬上限须通过内容取舍解决。

## 先划分主题模块，再安排场景

主题模块是一组共同解释一个机制的场景，不等于每个渲染文件或章节编号。多主题视频先给出简明路线图，说明各模块解决什么子问题，后续用当前主题标记或回到总图帮助定位。

每个主要模块在实际旁白和画面中完成以下闭环，篇幅按难度决定：

1. **开题**：明确“现在讲什么”，遇到了什么需要解决的问题。给出可理解的宏观定义、输入输出，以及它在整体任务中的作用；不能只给模块标题。
2. **展开**：分步建立对象、条件和操作。上一阶段得到的对象是下一阶段的输入或依据，明确说出并展示这层关系。
3. **综合**：用刚才建立的对象和结果重组完整机制，回答起始问题。不是只列术语，也不是机械重复最后一个公式。
4. **衔接**：说明当前结果仍缺少什么，或下一模块怎样使用它；完成全片目标后不强行提出新问题。

例如，Attention 模块先说明“每个接收位置怎样按需要汇集输入信息”，再解释匹配、归一化和加权汇集，最后把三步连回输入与输出。进入 Encoder 时说明它如何利用这种信息交换形成上下文表示；进入 Decoder 时说明为什么还需要依据已生成前缀逐步预测。这个例子说明层次关系，不要求所有视频采用 Transformer 或相同模块数量。

## 在运算之前建立共同语言

全片先规划统一符号表，开头讲清贯穿全片的基本对象及表示方式；局部新增符号在首次运算前定义。符号表必须落实到讲解和画面，不能仅留在作者文档，也不要一次朗读尚无语境的所有符号。

依内容说明符号代表标量、向量、矩阵、序列还是函数，索引枚举什么，维度由什么决定。约定行/列向量、堆叠方向和符号作用范围；用具体对象对应抽象表示。观众必须能区分对象本身与它的数值表示。

例如先用实际词元解释序列 x=(x₁,…,xₙ)，再定义每个词元的向量 eᵢ，以及按行堆叠的 X∈Rⁿˣᵈ；说明 n 是序列长度，d 是特征宽度，输出序列 y=(y₁,…,yₘ) 的长度 m 可不同。以后引入 Q、K、V 时再定义它们的来源和形状。不能让同一个 xᵢ 无说明地从词元变成向量，也不能悄悄改变索引或行列约定。

## 选择与内容相符的路线

| 解释任务 | 可采用的推进方式 | 选择依据 |
|---|---|---|
| 概念 | 熟悉现象或关系 → 转换表征 → 建立新概念 → 改变参数 → 用于新问题 | 一个已有认识可以连接到新的理解方式 |
| 工具机制 | 展示能做什么 → 追问内部机制 → 拆出简单组成部分 → 组合 → 回到实际使用 | 观众会使用结果但缺少对运作过程的理解 |
| 证明 | 具体任务或非正式结论 → 检验尝试或猜想 → 关键构造 → 追踪条件与结论 → 回答原问题 | 核心价值是为什么结论必然成立或某任务不可能 |
| 两种表征 | 解释同一对象的两个视角 → 建立对应 → 用一个视角解读另一个 | 几何、代数、数值或物理意义之间的联系是关键 |
| 特例到推广 | 一个可跟踪的例子 → 找到起作用的关系 → 给出推广理由 → 检查新情形 | 相同结构能在更广的范围继续使用 |

可以组合路线。结论可以提前出现；真实的困难、反例或方法局限才适合推动转折，不要强行假设观众犯错。历史叙事只在来源支持且确实帮助理解时使用。

## 让贯穿例子承担持续的解释任务

选择容易进入、能承载核心关系、加入条件后仍可使用的例子。每次返回时增加一个理解层次，例如从观察现象到参数作用，再到一般表达式。

新例子应有明确用途：检验猜想、展示适用范围、提供反例，或说明旧例子没有覆盖的情况。例子不能自行证明一般结论，推广时要说明为什么仍然成立。

## 旁白推进思考的动作

一个自然句或短句组围绕一个主要动作展开；它不必对应一个新镜头。

| 动作 | 旁白应当说清什么 |
|---|---|
| 建立动机 | 遇到了什么问题，为什么值得理解 |
| 建立对象 | 点、箭头、参数、函数或装置代表什么 |
| 解释条件 | 哪些量可变、哪些不变，为什么需要这个限制 |
| 邀请预测 | 按当前理解，改变一个量应发生什么 |
| 引导观察 | 此刻注意哪个对象或差异 |
| 解释结果 | 刚才的变化说明什么，为什么成立 |
| 修正或转折 | 尝试哪里不足，下一步因而需要什么 |

把抽象术语转成行为、限制或后果：连续性可以联系到对象不会突然跳变，乘数可以联系到长度与方向，积分可以联系到局部贡献的累积。仍要保留该解释成立的条件。解释后，观众应能判断一个具体例子或作出预测。

在关键转折处提出合理疑问，如为什么选择这个形式、另一个直观方法为何不足、局部可行是否意味着整体可行。随后用推理或操作回答，不把反问当作每段必需的修辞。

可以邀请观众想象、比较，或承认某一步初看很奇怪。复杂处换一个视角、补中间步骤或回看变化；重复时应增加可用的解释。

## 声画分工与段落结束

旁白交代为什么做、看哪里、结果意味着什么；图形执行变化、保留对应关系、提供比较；画面文字保存需要同时参照的名称、条件和公式。字幕与补充注释的分离遵循 [脚本契约](audio-first-script.md)。决定结论的前提应在需要时讲清并留作参照。

单个小场景可以结束于得到的结果或自然产生的下一个问题，不必逐场复述。主要主题模块必须有明确总结：重连各步关系、解释输入怎样成为输出，并回答本模块的问题。全片结束时再把模块连回最初的任务，必要时用一个变化后的例子检验观众能否迁移理解。

不按片长套固定的开场、主体与回顾比例。内容难度决定哪里需要观察时间；正式制作的计时遵循实测配音时间轴。
